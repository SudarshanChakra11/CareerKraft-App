# CareerKraft 🚀

AI-powered personalized career guidance platform that helps students discover career paths, generate adaptive learning roadmaps, track progress, and get AI-based mentorship support.

---

## 📌 Overview

CareerKraft is an intelligent career guidance platform designed to solve the problem of career confusion among students and freshers.

The platform analyzes user interests, skills, and goals to generate:
- Personalized career recommendations
- Adaptive AI learning roadmaps
- Skill-gap analysis
- Segmented learning plans
- AI chatbot assistance
- Progress tracking system

---

## ✨ Features

### 🎯 Personalized Career Suggestions
- Career recommendations based on assessment
- AI-driven skill analysis
- Domain-specific guidance

### 🧠 AI Adaptive Roadmap
- Dynamic roadmap generation
- Personalized learning sequence
- Progress-based adaptation

### 📚 Learning Segmentation
- Large learning goals divided into manageable chunks
- Weekly and monthly milestones
- Topic-wise learning flow

### 🤖 AI Chatbot Mentor
- AI-powered student support chatbot
- Career-related doubt solving
- Learning assistance

### 📊 Progress Tracking
- User progress dashboard
- Skill completion tracking
- Goal monitoring system

### 🔐 Authentication System
- User login/signup
- Secure authentication
- Protected routes
